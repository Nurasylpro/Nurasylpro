# Nurassyl

I build robots and computer vision systems, from mechanical design to the models that drive them.

## Featured

### [Weedzap](https://github.com/Nurasylpro/Weedzap)
Laser weeding robot. A camera and a YOLO model trained on my own weed dataset find each weed, and a gantry aims a high-power laser at it.

### [clueless](https://github.com/Nurasylpro/clueless)
Study tool that animates code execution step by step. Built with a team.

### [cadmium-car-smoke-detection](https://github.com/Nurasylpro/cadmium-car-smoke-detection)
Detects vehicles with smoking exhaust in street video and reads their license plates. Hackathon project.
